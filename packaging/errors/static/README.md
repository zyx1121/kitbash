# static

Served next to the error pages at `/errors/static/`:

- `InterVariable.woff2`: the Latin subset of Inter 4.1 that every zyx.tw site
  serves, copied byte for byte from `packages/ui/src/fonts/` in
  [zyx1121/www.zyx.tw](https://github.com/zyx1121/www.zyx.tw), whose README
  there has the subset command. SIL Open Font License 1.1, see
  [LICENSE.txt](LICENSE.txt), which is served with it.
- `favicon.ico`: the zyx mark icon from `apps/web/app/favicon.ico` in the same
  repo.
